# portfolio-website
AWS S3 Static Portfolio Website hosted using Amazon S3 and CloudFront with HTTPS.
## Project Overview

This project demonstrates hosting a responsive portfolio website using HTML, CSS, AWS S3, and CloudFront.

## Features

- Responsive Design
- Hero Section
- About Section
- Project Cards
- Contact Section
- Footer
- Google Fonts
- Font Awesome Icons

## Technologies Used

- HTML
- CSS
- GitHub
- AWS S3
- AWS CloudFront

## Project Structure

portfolio-website/
├── index.html
├── styles.css
└── README.md

## Deployment Steps

1. Create the portfolio website using HTML and CSS.
2. Upload code to GitHub.
3. Create an S3 bucket.
4. Enable Static Website Hosting.
5. Upload website files.
6. Configure Bucket Policy.
7. Create CloudFront Distribution.
8. Access the website using HTTPS.
